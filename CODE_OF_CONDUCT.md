# Code of conduct

We want PageToVid's spaces — issues, discussions, pull requests — to be welcoming, respectful and
useful to everyone.

**Expected:** be kind and constructive; assume good intent; keep discussions on topic; respect
people's time and privacy.

**Not accepted:** harassment, insults or personal attacks; discriminatory language; sharing someone
else's private information; spam or deliberately disruptive behaviour.

**Enforcement:** maintainers may edit or remove content and restrict participation for behaviour that
breaks this code. Report problems to **hello@pagetovid.com (subject: "Conduct")**; reports are handled confidentially.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
