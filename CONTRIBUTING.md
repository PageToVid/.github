# Contributing

Thanks for helping improve PageToVid.

## Documentation

The documentation lives in [PageToVid/docs](https://github.com/PageToVid/docs) and anyone can
propose a change:

1. Use **"Edit this page on GitHub"** at the bottom of any docs page, or fork the repository.
2. Keep one change per pull request, and say *why* in the description.
3. The MCP [tool reference](https://pagetovid.github.io/docs/mcp/tools) is **generated** from the
   server — do not edit it by hand; open an issue instead if something in it is wrong.

## Bugs and ideas

Open an issue with the template that fits. For a bug, include the video id (it is in the project
URL), what you expected, and what happened. Never paste an API key or a session token.

## Code

The product source is private. If you would like to contribute code, open an issue first so we can
talk about it.
