# Getting help

- **Docs:** https://pagetovid.github.io/docs/
- **Something is broken:** open a [bug report](https://github.com/PageToVid/docs/issues/new?template=bug_report.yml) — include the video id.
- **An idea:** open a [feature request](https://github.com/PageToVid/docs/issues/new?template=feature_request.yml).
- **Account or billing:** hello@pagetovid.com
- **Security:** see [SECURITY.md](SECURITY.md) — never report it in public.
